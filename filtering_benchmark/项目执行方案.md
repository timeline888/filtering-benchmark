# 旋转机械振动/声学信号滤波降噪评估系统 — 项目执行方案

## 1. 项目概述

### 1.1 项目目标

构建一套**全面的滤波降噪算法评估平台**，用于对旋转机械（轴承、齿轮、转子等）的振动/声学信号进行系统化的滤波降噪效果评估。平台集成多种主流滤波算法，通过统一的信号输入、多维度指标计算和综合评分排名，为工程实践中的滤波算法选型提供量化依据。

### 1.2 核心能力

- **算法覆盖**: 71 种滤波降噪算法，涵盖 13 个类别
- **指标评估**: 20 种质量指标，覆盖时域、频域、包络、感知、效率 5 个维度
- **评价方法**: 4 种综合评分法（加权求和、TOPSIS、Borda计数、Pareto前沿）
- **可视化**: 时域波形、频谱、包络谱、算法对比矩阵、全方位导出
- **扩展性**: 声明式注册机制，新增算法仅需一行装饰器

## 5. 评估流水线 (7阶段)

```
Stage 1: 信号加载       → PipelineContext.original_signal
    ├── 仿真信号生成（轴承故障模型）
    └── 文件读取（CSV/MAT/TDMS/WAV/HDF5）
         ↓
Stage 2: 信号预处理     → PipelineContext.preprocessed_signal
    ├── 去直流分量 (remove_dc)
    ├── 重采样 (resample)
    ├── 幅值归一化 (normalize)
    └── 通道选择 (channel_select)
         ↓
Stage 3: 并行滤波降噪   → PipelineContext.denoised_results
    ├── 算法选择 (all/selected/category)
    ├── 并行执行 (sequential/multiprocessing/ray)
    ├── 超时保护 (timeout=300s)
    └── 异常隔离
         ↓
Stage 4: 包络谱分析     → PipelineContext.envelope_results
    ├── Hilbert包络提取
    ├── 包络谱计算
    ├── 故障频率匹配
    └── 谐波检测
         ↓
Stage 5: 指标计算       → PipelineContext.metric_scores
    ├── 时域指标 (4项)
    ├── 频域指标 (4项)
    ├── 包络指标 (4项)
    ├── 感知指标 (4项)
    └── 效率指标 (4项)
         ↓
Stage 6: 综合评分       → PipelineContext.metric_scores.normalized
    ├── 归一化 (minmax/zscore/rank)
    ├── 评分 (weighted_sum/topsis/borda/pareto)
    └── NaN/Inf 鲁棒处理
         ↓
Stage 7: 排序与报告     → PipelineContext.report
    ├── 综合排序 (overall_ranking)
    ├── 分类排序 (category_ranking)
    ├── 报告生成 (text/json/csv/markdown)
    └── 图表导出 (png/svg/pdf)
```

## 7. 核心设计模式

### 7.1 算法注册机制
```python
@register_algorithm(
    name="小波阈值降噪",
    category=AlgorithmCategory.WAVELET,
    complexity=AlgorithmComplexity.MEDIUM,
    tags=["wavelet", "threshold", "denoising"],
)
class DwtThresholdDenoise(BaseAlgorithm):
    default_params: ClassVar[Dict[str, Any]] = {
        "wavelet": "db4",
        "level": 4,
        "threshold_method": "universal",
    }

    @log_execution
    @validate_params
    def denoise(self, signal, sample_rate, **kwargs):
        # 算法实现
        ...
```

### 7.2 装饰器链
- `@register_algorithm` — 注入元信息 (name/category/complexity/tags)，注册到 Registry
- `@log_execution` — 自动记录输入shape/耗时/异常
- `@validate_params` — 自动调用 `_validate_runtime_params` 校验参数

### 7.3 回退策略
所有可选依赖算法实现两级回退：
- **优先路径**: 使用第三方库（pywt/scipy/sklearn/torch）
- **回退路径**: 手动实现核心逻辑或返回原始信号并发出 warning
